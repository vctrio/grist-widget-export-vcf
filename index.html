Configuration nécessaire. Dans le panneau de droite de Grist (onglet du widget), associez au minimum la colonne Nom, puis les autres champs disponibles (prénom, téléphone, email…).

Filtrer les contacts

Voir la liste
    L'extension .vcf est ajoutée automatiquement.

    Pour n'exporter qu'une partie des contacts, associez une colonne au champ « Critère de filtre » (catégorie, statut…) dans le panneau de configuration du widget, puis cochez les valeurs voulues ci-dessus. Le fichier est créé dans votre navigateur, aucune donnée n'est envoyée ailleurs.
